## Блокирующие вопросы для промышленного релиза

1. **Развернутый frontend старее проверенной ветки.** В публичном `index.html` production всё ещё подключен `/mro/fonts.css` с HRM-шрифтом; в кандидате используется bundled Golos. Текущий production — не коммит `d11909c` и не данный QA-кандидат.
2. **Backend production не совпадает с workspace-тестами:** 59 PHP-файлов имеют содержательные различия при нормализации CRLF/LF; тестовое `app/Support/ToirTransaction.php` отсутствует в deployed backend. Следовательно, 92 pass не равны приемке exact production build.
3. **Реальные end-to-end процессы ещё не проверялись:** cross-company access с живыми QA-аккаунтами, создание заявки → наряд → приемка → списание склада → PDF, серверный SMTP (фактическая доставка), Reverb/WebSocket при двух сеансах, супер-админские изменения и тарификация.
4. **Технический долг:** предупреждения Sass `@import` и основного чанка >500 kB; отдельные специализированные кнопки остались нативными намеренно, нужен ручной UX-аудит по графикам/демо.
